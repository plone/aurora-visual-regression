# Plone Aurora visual regression baselines

This repository stores the baseline screenshots of the [Plone Aurora](https://github.com/plone/aurora) visual regression tests.

It is managed by the **Update VRT Screenshots** workflow of `plone/aurora`.
Don't add or change screenshots by hand.

See [Visual regression tests](https://plone-aurora.readthedocs.io/contributing/visual-regression-tests.html) in the Plone Aurora documentation.
